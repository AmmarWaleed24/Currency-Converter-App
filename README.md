# 💱 Live Currency Converter

A modern, highly responsive Currency Converter web application built from scratch using clean, standard Web Technologies. The app fetches real-time, accurate exchange rates from a live financial API.

## ✨ Key Features
- **Live API Integration:** Uses the Fetch API (`async/await`) to pull accurate, up-to-the-minute exchange rates dynamically.
- **Pixel-Perfect UI:** Built with an elegant Dark-Mode theme suited for modern banking apps.
- **Flawless CSS Grid Alignment:** Custom-engineered input layouts and dropdown structures ensuring zero distortion or alignment breakage on any text length.
- **Custom Form Controls:** Replaced default browser select arrows with a clean, hardcoded SVG icon for cross-browser visual consistency.
- **Fully Responsive:** Smooth scaling across mobile devices, tablets, and desktop displays.

## 🛠️ Built With
- **HTML5:** Clean, semantic structure.
- **CSS3:** Advanced Grid Layout, CSS Custom Variables, and responsive breakpoints.
- **Vanilla JavaScript:** Asynchronous programming, DOM updates, and error handling.
